XitForge: archivos por tunel

Este modulo utiliza idevice v0.1.68 con extensiones locales para transporte binario, deteccion RSD y recuperacion AFC. Incluye acceso nativo MHA-C2 de solo lectura, CoreDevice FileService, HouseArrest y enumeracion de directorios mediante AirTraffic/ATAirlock. La lectura de archivos mediante AirTraffic no esta incluida.

Referencia de interfaces y comportamiento MHA-C2: MobileHouseArrest-PoC (https://github.com/0xjohnnydev/MobileHouseArrest-PoC) e inspeccion del IPA 3105 suministrado. XFMHAContainerAccess es una implementacion independiente; no incorpora codigo GPL del proyecto 3105. La concesion alternativa BadQuery se limita a los cuatro builds beta reconocidos por ese ejecutable; XFContainerGrant es un puente independiente y solo se usa para lectura de contenedores de apps/grupos validados. Referencia primaria: https://github.com/forcequitOS/bad_query. Los cambios locales de FileService acotan sus operaciones y limitan la reserva de memoria de las descargas.

XitForge known-file module revision 1.3.1
The known-file read/replacement/deletion transactions and recovery classifier are
independently implemented. Protocol interfaces were checked against the
user-supplied 3105 executable and public AirLift research. No 3105 executable
code is copied into this module. Reads temporarily relocate existing files.
Deletion retains a durable local original. The source picker imports a copy,
with a cancellable, bounded background read after the picker returns.
